# P1-01 — UI foundation primitives

## What I built

Implemented the 13 shared native UI primitives owned by P1-01:

- Semantic `Text` typography with token-typed color, weight, and six named variants.
- `Button` and `IconButton` with all web variants/sizes, Reanimated 150ms press treatment,
  loading-width preservation, disabled behavior, semantic haptics, accessible names, and 44pt minimum
  hit areas.
- A compile-time-typed `Icon` wrapper containing all 108 Lucide names catalogued by
  `research/01`. Every listed name exists in `lucide-react-native@1.14.0`; no substitutions were
  needed.
- Elevated/flat `Card`, all canonical and `*-soft` `Badge`/`Chip` treatments, both `Divider`
  hairlines, deterministic semantic-color `Monogram`, and composable `EmptyState`.
- Token-timed `StatusDot`, `Spinner`, and `Skeleton` animations. Reduce Motion is read
  synchronously from Reanimated for first paint and kept current through `AccessibilityInfo`;
  StatusDot and Skeleton become static when enabled.
- Three focused test suites covering both themes, variant matrices, accessibility, touch targets,
  haptics, loading behavior, reduced motion, monogram determinism, and icon-name typing.

All visual values come from `@/theme`. There are no literal hex colors in the implementation and
no animation imports from React Native's legacy `Animated` API.

## Public component signatures

These are the interfaces Phase 2 can consume through direct file imports.

### `Text`

```ts
export type TextVariant = "title" | "body" | "label" | "caption" | "mono" | "micro";
export type TextColor = keyof Colors;
export type TextWeight = "light" | "normal" | "medium" | "semibold";

export interface TextProps extends NativeTextProps {
  children?: ReactNode;
  color?: TextColor;       // default: foreground
  variant?: TextVariant;   // default: body
  weight?: TextWeight;
}

export function Text(props: TextProps): React.JSX.Element;
```

### `Button`

```ts
export type ButtonVariant =
  | "default" | "secondary" | "outline" | "ghost" | "destructive" | "link";
export type ButtonSize = "default" | "sm" | "lg" | "icon";

export interface ButtonProps extends Omit<
  PressableProps,
  "accessibilityRole" | "children" | "disabled" | "hitSlop" | "style"
> {
  children: ReactNode;
  disabled?: boolean;
  loading?: boolean;
  size?: ButtonSize;          // default: default
  style?: StyleProp<ViewStyle>;
  variant?: ButtonVariant;    // default: default
}

export function Button(props: ButtonProps): React.JSX.Element;
```

Text/number children are automatically rendered through the shared `Text` primitive and supply the
accessible name. Icon/custom children should pass an explicit `accessibilityLabel`. Loading keeps
the original content invisibly mounted, overlays `Spinner`, exposes `busy: true`, and disables
presses. The exported `buttonContentColor(variant)` helper is used by `IconButton` to keep glyph
color aligned with the button variant.

### `IconButton`

```ts
export type IconButtonSize = "default" | "sm" | "lg";

export interface IconButtonProps
  extends Omit<ButtonProps, "accessibilityLabel" | "children" | "size"> {
  accessibilityLabel: string;
  icon: IconName;
  size?: IconButtonSize;       // default: default
}

export function IconButton(props: IconButtonProps): React.JSX.Element;
```

The default variant is `ghost`. All sizes retain their exact 36/40/44pt visual box while hit slop
expands smaller sizes to at least 44pt.

### `Icon`

```ts
export type IconName = keyof typeof iconSet; // the 108 researched Lucide names

export interface IconProps {
  accessibilityLabel?: string;
  color?: keyof Colors;          // default: foreground
  name: IconName;
  size?: number;                 // default: 16
  testID?: string;
}

export function Icon(props: IconProps): React.JSX.Element;
```

Icons without a label are decorative and hidden from the accessibility tree. Labeled icons expose
the image role.

### `Card`

```ts
export type CardVariant = "elevated" | "flat";

export interface CardProps extends PropsWithChildren<Omit<ViewProps, "style">> {
  padded?: boolean;              // default: true (16pt)
  style?: StyleProp<ViewStyle>;
  variant?: CardVariant;         // default: elevated
}

export function Card(props: CardProps): React.JSX.Element;
```

Both variants use the exact card ground, foreground-compatible border, and 10pt radius. Elevated
adds the shared `shadow.sm`; flat omits it.

### `Badge` and `Chip`

```ts
export type BadgeVariant =
  | "default" | "outline"
  | "success" | "warning" | "info" | "destructive"
  | "success-soft" | "warning-soft" | "info-soft" | "destructive-soft";

export interface BadgeProps {
  children: ReactNode;
  style?: StyleProp<ViewStyle>;
  testID?: string;
  variant?: BadgeVariant;        // default: default
}

export function Badge(props: BadgeProps): React.JSX.Element;
export type ChipVariant = BadgeVariant;
export type ChipProps = BadgeProps;
export function Chip(props: ChipProps): React.JSX.Element;
```

All semantic variants use the researched soft background plus a 25% semantic border and semantic
text. The `*-soft` names are compatibility aliases to that same web recipe.

### `Spinner`

```ts
export interface SpinnerProps {

  size?: number;                  // default: 16
  testID?: string;

export function Spinner(props: SpinnerProps): React.JSX.Element;
```

The SVG geometry is the exact web track/arc and rotates at the tokenized 1s linear rate.

### `Skeleton`

```ts
export interface SkeletonProps {
  style?: StyleProp<ViewStyle>;
  testID?: string;
}

export function Skeleton(props: SkeletonProps): React.JSX.Element;
```

Callers supply dimensions through `style`; the primitive supplies muted fill, 8pt radius, and the
tokenized 2s opacity cycle.

  orientation?: DividerOrientation; // default: horizontal

  testID?: string;

### `Monogram`

```ts
export interface MonogramProps {
  accessibilityLabel?: string;       // default: seed
  seed: string;
  size?: number;                     // default: 28
  style?: StyleProp<ViewStyle>;
  testID?: string;
}

export function Monogram(props: MonogramProps): React.JSX.Element;
```

`monogramLetter(seed)` and `monogramPaletteIndex(seed)` are also exported for deterministic domain
tests and callers that need to preview the fallback identity.

### `EmptyState`

```ts
export interface EmptyStateProps {
  action?: ReactNode;
  description?: ReactNode;
  icon?: IconName | ReactElement;
  iconPlate?: boolean;               // default: true
  style?: StyleProp<ViewStyle>;
  testID?: string;
  title: string;
}

export function EmptyState(props: EmptyStateProps): React.JSX.Element;
```

Pass a ready-made `Button` as `action` so the feature owns its handler/variant. An `IconName` gets
the standard 48pt plate and muted treatment; a custom element supports already-plated brand marks.

## Deviations and research notes

1. P1-01 says Skeleton should “shimmer,” but authoritative `research/01` identifies the actual web
   primitive as `animate-pulse`: opacity `1 → .5 → 1`, 2s, pulse easing. The implementation
   follows that executable-web transcription rather than inventing a directional gradient shimmer.
2. The plan explicitly names `*-soft` Badge/Chip variants, while the web/report names the six
   visual recipes `default | outline | success | warning | info | destructive`; the four semantic
   recipes already use soft fills. Both naming forms are exported and resolve to the same exact
   visual recipe.
3. The report documents only the elevated web Card container; P1-01 additionally requires
   elevated and flat native treatments. `flat` is the same card surface without `shadow.sm`, and
   `padded={false}` allows composition equivalent to the web Card shell.
4. There is no global web `Chip` primitive. The native plan requires one, so it deliberately shares
   Badge's exact small status-pill anatomy rather than importing behavior from feature-specific web
   chips.
5. I consulted the web source only for `EmptyState`'s caller-supplied action shape and to confirm the
   absence of a global Chip, because the reports did not state those prop-level details. No report
   value was found to be incorrect.
