# F-01 — Push-style navigation drawer

## What I built

- Replaced the Expo Router bottom-tab shell with an official Drawer navigator configured with
  `drawerType: "back"`, so application content moves right to reveal the menu underneath.
- Removed the root Files destination and route. Host Files remains contextual at
  `/host/[id]/files`.
- Added a themed custom drawer with Workspaces, Hosts, Legion, and Settings, plus Admin only when
  `me.user.is_admin` is true. Active rows use the web-sidebar-derived 44pt hit / 40pt visual
  geometry, 10pt gutters, 36pt icon slots, and theme accent/foreground roles.
- Added accessible burger controls without open/close haptics. Root screens use the burger on the
  left; nested screens keep native Back on the left and expose the burger on the right.
- Added `haptics.selection()` exactly once when a drawer destination is selected.
- Moved the authenticated workspace, host, settings, and admin route files under URL-invisible
  `(drawer)`, preserving public `/workspaces`, `/workspace/:id`, `/hosts`, `/host/:id`, `/legion`,
  `/settings/*`, and `/admin/*` paths. Terminal remains at root above the drawer shell.
- Changed deep-link resolver output for Legion and Settings from internal `(tabs)` names to stable,
  public group-independent paths.

The drawer open gesture uses a 20pt `swipeEdgeWidth`. That gives the workspace horizontal pager
ownership everywhere except the extreme left edge. The terminal overlay is outside the drawer
navigator in the root stack, so its full-surface dismissal gesture does not compete with drawer
opening.

`@react-navigation/drawer` was already installed by the orchestrator as requested in the shared
brief. The resolved version is **7.13.9** (`package.json` remains at the orchestrator's
`^7.5.0` declaration); I did not reinstall or change dependencies.
