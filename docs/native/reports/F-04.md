## Deviations from the plan/research

- `app.json` still has the display name `spawn`. F-04 owns only its icon/splash/adaptive configuration, so changing the broader app identity field would exceed the explicit file-line ownership boundary.
- The auth shell itself uses fixed Pressroom tokens, but its child `Button`, `Input`, and `Field` controls still consume the product `useTheme()` context. That context is not publicly overridable and the shared controls/theme files are outside F-04 ownership, so a fully scoped grimoire control skin could not be added safely.
- Research recommends a canonical component under `components/agents/`; the implementation remains at the plan's frozen owned path, `components/workspace-detail/agent-icon.tsx`, and call sites import it directly.
- No simulator, Expo Go, screenshot, or manual visual verification was performed, as required by the campaign rules.
