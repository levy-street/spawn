# R4-04 — Hosts, host detail and Legion: one header each

## What I built

- Replaced the Hosts, Legion, host-detail, and host-agents bespoke safe-area/header bands with a single global `AppHeader` passed through `Screen.header`.
- Added the specified Hosts header actions for Legion, Settings, and host connection; retained the existing fleet overview and host list behavior.
- Moved the Legion fleet rollup into the header subtitle and the live-capacity switch into the header accessory.
- Removed redundant route-level `Screen` wrappers so each screen has one layout owner and one top inset owner.
- Replaced the host-files route's native `Stack.Screen` title with `AppHeader`, because native headers are disabled app-wide.
- Standardised owned bordered surfaces, rows, separators, section headings, and local empty states with `Card`, `ListRow`, `ListSeparator`, `SectionHeader`, and `EmptyState`.
- Added render tests covering unique titles, Hosts header navigation, Legion subtitle/accessory behavior, and host-detail/host-agents header context.
