# R5-03 — Keyboard motion: animate the inset, close the gap

## What I built

- Replaced the footer's keyboard-visibility state switch with `react-native-keyboard-controller`'s continuous Reanimated `height` and `progress` values.
- Made `KeyboardScreen` the keyboard-animation owner. It supplies the shared values to the global `FooterActions` primitive and records the transition's destination progress from controller start/end events for the reduced-motion path.
- Made `FooterActions` itself the animated surface, so the Cancel / Create footer translates with the keyboard while its bottom padding interpolates on the same native progress and curve.
- Interpolated bottom padding from the closed safe-area-aware value to only `sizing.footer.minimumBottomPadding` while open. A 34pt home-indicator inset therefore finishes at 12pt above the keyboard, not 46pt.
- Removed `FooterActions`' independent `useKeyboardState` visibility listener.
- Applied `useReducedMotion`: the inset reads the keyboard event's destination immediately instead of traversing intermediate progress values.
- Added integration and primitive coverage for continuous midpoint/full-open frames, translated keyboard height, safe-inset removal, controller start-event wiring, and immediate reduced-motion settling.

The motion skills kept this deliberately limited to the one functional transition: coordinated keyboard/footer movement, with no decorative animation and an accessibility-safe immediate path.
