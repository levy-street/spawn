# P3-03 — Motion, haptics and performance audit

## Outcome

Completed the source-level polish audit across every assembled route and shared interaction
surface. I applied only the narrow corrections allowed by the P3-03 plan: token/reduced-motion
wiring and isolated haptic corrections. The final tree passes TypeScript, repository-wide Biome,
and all 133 Jest suites.

The audit found no direct `expo-haptics` imports outside the central adapter (and its adapter test),
no non-gesture spring added to a copied web interaction, no per-frame gesture state crossing to
React, and no terminal refit during the soft-keyboard transition. The remaining high-priority work
is concentrated in terminal connection/upload motion and workspace list subscription identity.

The `polish` and required `impeccable` skill passes shaped the systematic surface inventory and
micro-detail review. The campaign's frozen design tokens and strict ownership rules remained the
authority; I did not expand the visual design or restructure another agent's feature.

## Checklist result

### Motion

- Shared 150 ms default, 200 ms shell, 220 ms sheet, dialog fade/95%-scale, toast and repeat
  animations use the shared theme/motion tokens.
- The sheet now explicitly receives the exact 220 ms ease-out timing configuration.
- Auth navigation and workspace-icon crossfade now collapse under Reduce Motion.
- Tab-strip programmatic scrolling no longer animates under Reduce Motion.
- Reanimated springs occur only for gesture settle/rubber-band behavior.
- F-01, F-02 and F-07 are the remaining motion findings.

### Haptics

- Production access is centralized in `src/lib/haptics.ts`; components do not import
  `expo-haptics` directly.
- Tab settle, ordinary selection, default/destructive button, overlay, swipe, mutation,
  terminal-ready/disconnect and long-press paths were traced against P1-04's table.
- Removed terminal-output bell feedback and direct result haptics already supplied by toasts.
- Added missing list/destination selection and context-menu long-press feedback.
- F-04, F-08 and F-09 cover the remaining consistency gaps.

### Performance

- Workspace paging uses native `PagerView`; gesture transforms and thresholds stay on the UI
  runtime and cross to JS only for semantic haptic/commit callbacks.
- Terminal bytes and scrollback remain in the WebView terminal surface rather than React rows.
- The keyboard-fit gate suppresses fitting through `keyboardWillShow/WillHide` and schedules one
  fit after `keyboardDidShow/DidHide`; its focused suite passes.
- Rendered images have explicit dimensions. Shared workspace icons use cached `expo-image`.
- F-02, F-03, F-05 and F-06 are the remaining performance findings.

  findings.

  per the campaign's automated-verification-only rule.
