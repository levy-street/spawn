# P1-04 — Motion, gestures and haptics

## What I built

Implemented the complete Phase-1 native interaction foundation owned by P1-04:

- A safe, rate-limited haptic vocabulary with an enable/disable preference switch.
- Semantic duration and easing aliases over the authoritative scaffold theme tokens.
- Live system Reduce Motion tracking, a pure motion fallback helper, and shared press-scale feedback.
- Worklet-safe projected drag commit/resting-offset decisions with boundary and velocity coverage.
- A native `react-native-pager-view` `TabPager` with finger-following progress, lazy page content,
  controlled/uncontrolled operation, and one haptic per settled page change.
- A UI-thread `SwipeableRow` with leading/trailing accessible actions, vertical-list gesture
  arbitration, rubber-band resistance, reveal/commit haptics, destructive full-swipe commit, and
  an imperative `close()` handle.

The `animate`/`impeccable` guidance reinforced the implementation choices already required by the
plan: transform-only animation, UI-thread frame updates, restrained timing, and explicit reduced
motion. It did not change the frozen spawn motion tokens or introduce decorative motion.

## Public API

### `@/lib/haptics`

```ts
export function setEnabled(enabled: boolean): void;

export const haptics: {
  selection(): void;
  impact(weight: "light" | "medium" | "heavy"): void;
  success(): void;
  warning(): void;
  error(): void;
  overlayOpen(): void;
  overlayDismiss(): void;
};
```

Every method is fire-and-forget and swallows both synchronous failures and rejected native
promises. Identical physical feedback within 50ms collapses to one native request. Toggling the
preference clears the rate-limit history. `overlayOpen()` maps to a light impact;
`overlayDismiss()` maps to a medium impact.

### `@/lib/motion/reduced-motion`

```ts
export function useReducedMotion(): boolean;
export function motionSafe<T>(animatedValue: T, fallback: T, reducedMotion?: boolean): T;
```

The hook reads `AccessibilityInfo.isReduceMotionEnabled()` and subscribes to live
`reduceMotionChanged` events. The optional third helper argument lets a hook pass that live value
without introducing global mutable accessibility state.

### `@/lib/motion/use-press-scale`

```ts
export interface UsePressScaleOptions {
  disabled?: boolean;
  pressedScale?: number;
}

usePressScale(options?): {
  animatedStyle: { transform: Array<{ scale: number }> };
  onPressIn(): void;
  onPressOut(): void;
};
```

It uses the tokenized 150ms standard transition and tokenized press scale. Under Reduce Motion the
spatial transform remains at identity.

### `@/components/gestures/drag-threshold`

```ts
export interface DragDecisionInput {
  translation: number;
  velocity: number;
  size: number;
  threshold?: number;     // default 0.35
  projectionMs?: number;  // default 150
}

export function shouldCommitDrag(input: DragDecisionInput): boolean;
export function restingOffset(input: DragDecisionInput, committed: boolean): number;
```

Both functions are pure, carry a `"worklet"` directive, and have no Reanimated dependency.
Velocity projects the release point, but opposing velocity may only cancel a drag—it cannot commit
the interaction in the reverse direction.

### `@/components/gestures/tab-pager`

```ts
export interface TabPagerProps<Page> {
  pages: readonly Page[];
  renderPage(page: Page, index: number): ReactNode;
  page?: number;
  onPageChange?(page: number): void;
  onDragProgress?: SharedValue<number>;
  initialPage?: number;
  lazyWindow?: number; // default 1
  style?: StyleProp<ViewStyle>;
  testID?: string;
}
```

`onDragProgress.value` is continuously assigned `position + offset` inside the Reanimated event
worklet, so a Phase-2 tab strip can animate in lockstep without JS-thread frame callbacks. Distant
native page shells stay present for correct indices, but their React list content is not mounted.

`TabPager` uses `react-native-pager-view@6.9.1`, as preferred by the plan, because it supplies
finger-following native scroll physics and vertical-child gesture arbitration without per-frame
React state. Controlled page changes use the imperative pager API; under Reduce Motion they jump
without animation and native overdrag is disabled.

### `@/components/gestures/swipeable-row`

```ts
export type SwipeActionTone = "default" | "destructive";
export interface SwipeAction {
  key: string;
  label: string;
  icon: ReactNode | ((color: string) => ReactNode);
  tone?: SwipeActionTone;
  accessibilityLabel?: string;
  onPress(): void;
}
export interface SwipeableRowHandle { close(): void }
export interface SwipeableRowProps {
  children: ReactNode;
  leadingActions?: readonly SwipeAction[];
  trailingActions?: readonly SwipeAction[];
  style?: StyleProp<ViewStyle>;
  contentStyle?: StyleProp<ViewStyle>;
  testID?: string;
}
```

Actions are accessible 44pt-minimum buttons. The icon render-function form receives the resolved
tone color. Horizontal activation waits for 12pt while an 8pt vertical movement fails the gesture
so a nested vertical list wins early. A reveal gives one light impact; a destructive projected
full-swipe gives a warning at threshold while the finger is down, then commits on release.

## Haptic vocabulary

| Interaction | Haptic call |
|---|---|
| Tab change (pager settles on a new tab) | `haptics.selection()` |
| List row select / picker tick | `haptics.selection()` |
| Button press (default) | `haptics.impact("light")` |
| Destructive action press | `haptics.warning()` |
| Overlay presented | `haptics.overlayOpen()` |
| Drag crosses dismissal threshold | `haptics.overlayDismiss()` |
| Swipe row reveals an action | `haptics.impact("light")` |
| Swipe row commits a destructive action | `haptics.warning()` |
| Mutation succeeded (toast) | `haptics.success()` |
| Mutation failed (toast) | `haptics.error()` |
| Terminal connected / session ready | `haptics.success()` |
| Terminal disconnected unexpectedly | `haptics.error()` |
| Long-press context menu opens | `haptics.impact("medium")` |

## Deviations from plan

- None in deliverable scope or frozen interfaces.
- `TabPager` used the preferred native pager rather than a custom Gesture Handler pager.
- Swipe settling uses the existing 150ms tokenized ease-out timing rather than introducing spring
  constants. This preserves the plan's “no invented springs” requirement while finger tracking
  itself remains direct and UI-thread-bound.
- Where the broad research haptic table and the P1-04 plan table differ, the P1-04 specification
  is treated as authoritative, as required by the campaign instructions.

## Known gaps

- Physical-iPhone feel, frame pacing, native pager physics, and haptic hardware behavior remain
  unverified because device/manual testing is explicitly deferred to the human campaign pass.
- User-controlled pager dragging remains spatial under Reduce Motion because it is the direct,
  functional representation of the finger gesture. Programmatic changes are instant and overdrag
  is disabled; all authored timing-based spatial feedback collapses.
