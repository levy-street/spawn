# R5-05 — Host-row impeccable pass

## What I built

- Rebuilt `HostListItem` on the shared full-bleed `ListRow`; its outer height, padding, pressed state, copy layout, and touch behavior now come from the global row primitive.
- Anchored the online/offline `StatusDot` to a bordered server glyph, following the web host-list reference. Reachability no longer floats at the far-left edge without a machine association.
- Established a fixed reading order: host name first, connection/heartbeat second, platform and daemon version third, then session workload in a quiet outline `Badge`.
- Reduced the trailing edge from session count + chevron + overflow to a non-interactive workload badge and one overflow action. The whole row remains the open-host target; the ellipsis remains the manage-host target, and long press still opens the same action sheet.
- Rebuilt the fleet overview card's internal navigation row on `Card` + `ListRow` and added total session workload alongside its online/offline rollup.
- Added coverage for the attached status indicator, session badge, shared separators, fleet rollup/navigation, row navigation, isolated overflow action, and long-press action.

The impeccable pass changed the hierarchy, not the product language: machine identity and reachability now form one visual unit, operational metadata sits beneath it, workload is deliberately quieter, and management no longer competes with a redundant navigation chevron. The result stays dense, precise, and consistent with both the web reference and the native token system.
