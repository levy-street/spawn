# R4-02 — Global UI primitives

## What I built

- Deleted the Liquid Glass primitive and removed every glass/blur import from the owned app source.
- Replaced Dialog, Menu, and NativePopover glass with opaque `theme.colors.popover` surfaces, `popoverBorder` hairlines, the global `lg` radius, and their existing overlay elevation paths.
- Made the EmptyState container globally bordered and token-driven. Its required surface, border, radius, minimum height, and padding are applied after caller styles so call sites cannot opt out.
- Added the frozen `ListRow.shape` contract and exported `ListSeparator` with inset-by-default and edge-to-edge modes.
- Added the optional SearchField bottom-dock treatment using only `sizing.searchDock` and theme tokens.
- Added render/behavior coverage for every requested contract.
