# R4-03 — Workspaces list standardisation

## What I built

- Replaced the workspace route's native-header wiring and duplicate wrapper with one global `AppHeader` supplied through `Screen.header` in loading, error, and populated states.
- Preserved the existing `Plus`, `Server`, and `Settings` actions and their navigation/create behavior.
- Moved workspace search below the list into `Screen.footer`, enabled `SearchField.dock`, and thereby reused the shared keyboard-sticky footer path so search moves above the keyboard and clears the home indicator.
- Removed list-level horizontal gutters, opted workspace rows into `ListRow`'s `fullBleed` shape, and replaced the local gap separator with global `ListSeparator`.
- Preserved pull-to-refresh stability through `manualRefreshing`, plus existing row navigation, swipe/long-press actions, archived footer, mutations, confirmations, and dialogs.
- Added render coverage for one global header, docked keyboard-sticky search, rendered global separators, and square full-bleed row geometry.
