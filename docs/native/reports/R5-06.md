# R5-06 — Tab attention badge alignment

## What I built

- Added a shared workspace-detail `TabAttentionBadge` that composes the global `Badge` primitive and retains the canonical attention accessibility copy and severity tone.
- Centred the numeral inside a 20pt minimum plate on both axes with a 16pt micro line box, disabled extra font padding, centred text metrics, and tabular numerals for consistent digit side bearings.
- Centred the badge plate against the tab label through an explicitly centred wrapper.
- Kept the badge-to-label spacing on the existing `sizing.tab.labelGap` token; no literal gap was introduced.
- Added a regression test for the reported `2` count that asserts wrapper alignment, plate geometry, numeral metrics, and the tokenized inline gap.
- Audited the close `X` and connected flare: both already use symmetric, token-driven centring, so neither was changed. Reorder gestures, edge auto-scroll, haptics, close, selection, and accessibility behavior are unchanged.

The polish pass kept the fix constrained to typography and inline geometry and reused the established global badge, theme, and tab tokens.

- No changes were made to the correctly aligned close `X` or connected flare, per the instruction to change nothing unreported.
