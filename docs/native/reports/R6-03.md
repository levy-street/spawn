# R6-03 — Archived workspace navigation and full-bleed separators

## What I built

- Replaced the centred archived-workspaces footer link with a proper navigation row directly above workspace search. It composes the shared `ListRow` with an Archive icon, the `Archived workspaces` label, a visible singular/plural count, and a trailing chevron.
- Wired the row through selection haptics to `router.push("/workspaces/archived")` and added coverage for its exact placement, count, full-bleed row shape, and navigation behavior.
- Deleted `archived-workspaces-link.tsx`; the former footer treatment is gone rather than hidden.
- Bound the workspace `FlashList` separator to `<ListSeparator inset={false} />`. Regression coverage asserts a literal zero left margin on the rendered workspace-row divider.
- Added a named, documented `ListSeparatorProps` contract without changing its inset-by-default compatibility.
- Replaced the archived route's nested headerless `Screen` + longtail `SafeAreaView`/bespoke-header composition with an owned archived workspace screen. It uses one global `Screen` and `AppHeader`, shared `ListRow`/`ListSeparator` rows, and preserves the existing refresh, restore, permanent-delete, empty, loading, error, and workspace-open behavior.
- Split workspace top chrome, header declaration, and loading/error states by responsibility. `workspace-list-screen.tsx` is now 388 lines, below the round's ~400-line ceiling.

The Impeccable guidance kept the pass restrained: the change composes the established native primitives and tokens instead of adding workspace-local pressable, header, separator, or surface implementations.

## Separator audit

The inset variant still earns its place and remains the default. The final audit found active default-inset consumers in host destination rows, host session rows, and the pane list, where the divider intentionally starts after a leading icon/agent slot. Host fleet/skills, profile-menu, archived-card, and workspace separators explicitly choose full bleed. No dead branch was removed.
